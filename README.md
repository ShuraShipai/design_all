## Viewing the Designs

The design previews are stored as HTML files.

To view a design in your browser:

1. Open the project folder.
2. Locate the HTML file linked in the Projects table.
3. Download the repository or clone it locally.
4. Open the HTML file in a browser.

**Note:** GitHub may display HTML files as source code rather than as interactive webpages. Downloading the repository and opening the HTML files locally is the simplest way to view the actual designs.

## Purpose

This repository serves as a centralized archive of design previews and UI explorations across different projects. It makes it easier to browse, revisit, and compare the interfaces developed throughout my project work.
